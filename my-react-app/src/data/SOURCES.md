# UBC profile options

Verified: 2026-09-26. Scope: **UBC Vancouver only**.

## Official sources

- [UBC Vancouver Academic Calendar: Academic Programs](https://vancouver.calendar.ubc.ca/academic-programs) — undergraduate degree programmes and named specializations, including Arts, Engineering, Forestry, Land and Food Systems, Music, Education and professional undergraduate degrees.
- [UBC Science: 2026 specialization admission requirements](https://science.ubc.ca/students/spec-admission-requirements) — BSc majors and the listed combined majors/honours, including Data Science and Computer Science and Neuroscience.
- [UBC Sauder: BCom options](https://mybcom.sauder.ubc.ca/courses-money-enrolment/options) — Commerce and its ten named options. The labels explicitly identify Commerce: Sauder considers these options within the Commerce major.
- [UBC undergraduate programme directory](https://you.ubc.ca/programs/) — programme names and degree distinctions, including English specializations.
- [UBC Bachelor of Design](https://vancouver.calendar.ubc.ca/faculties-colleges-and-schools/school-architecture-and-landscape-architecture/bachelor-design-architecture-landscape-architecture-and-urbanism/introduction) — Design in Architecture, Landscape Architecture, and Urbanism.
- [UBC Vancouver Housing: Residences](https://vancouver.housing.ubc.ca/residences-rooms/residences/) and [Residence property](https://vancouver.housing.ubc.ca/residence-property/) — residence communities.

## Catalogue scope

The file contains 187 undergraduate programme/specialization choices and 17 UBC-managed residence communities, sorted alphabetically. Degree labels distinguish programmes with the same name. Residence communities are the housing choices; individual buildings or houses within those communities are not separate options. Graduate residences remain included because the housing request covers all residences.

Minor-only programmes, certificates, diplomas, graduate degrees, first-year entry cohorts (Arts One, Science One, Vantage), and medical teaching departments that are not separate undergraduate degrees are excluded. Older degree names remain where the current Calendar still lists them for continuing students.

This is a maintained snapshot, not a live university catalogue. It includes named combined majors listed in the sources, but does not enumerate every possible individually approved double major, every honours variant of an existing subject, or every concentration within a major. Unspecified broad subjects are retained when the Calendar offers that degree/programme choice. Update this file from these official sources when UBC changes its offerings.
